01

基础视觉风格 · refined-minimalism

精炼极简

Refined Minimalism

核心词条

以严格层级、充足留白和少量高价值元素表达清晰与可信，不依赖装饰制造所谓高级感。

它不是什么不是空白越多越好，也不是把所有内容缩成浅灰小字。

识别信号

  • 单一视觉主次
  • 大面积有效留白
  • 一到两个克制强调色

排除信号

  • 无目的的大空白
  • 低对比到难以阅读

七类视觉语法

字体
中性无衬线配少量高识别标题字
色彩
白、暖白或浅灰为主，单一品牌强调色
布局
稳定网格、短路径和明确首要动作
形状
简洁矩形与适度圆角
材质
哑光、轻边框、极浅阴影
图像
真实产品界面或克制摄影
动效
只在状态变化和页面进入时轻动
近义词边界与组合规则

容易混淆

  • editorial-swiss精炼极简优先减少元素，瑞士编辑式更强调可见网格与字体构成。
  • neumorphism精炼极简靠层级和留白，新拟态靠同色浮雕材质。

适合 / 避免

适合：SaaS 首屏、生产力工具、专业服务

避免：需要强烈娱乐刺激的活动页

可组合：bento-grid、dark-mode、productivity-saas

MODEL PROMPT

采用精炼极简：单一视觉主次；大面积有效留白；一到两个克制强调色。稳定网格、短路径和明确首要动作。

避免无目的的大空白、低对比到难以阅读。
02

基础视觉风格 · editorial-swiss

瑞士编辑式

Editorial Swiss

核心词条

把网页当成可交互的编辑版面，以严格网格、强字体层级和受控非对称组织信息。

它不是什么不是所有黑白红页面，也不是简单使用无衬线字体。

识别信号

  • 可见或隐含的严格网格
  • 大字号字体成为主视觉
  • 高对比信息层级

排除信号

  • 随意错位
  • 装饰压过内容结构

七类视觉语法

字体
粗细跨度大的无衬线与等宽辅助字
色彩
黑白为骨架，红或高纯度色作信号
布局
非对称网格、跨栏标题和精确基线
形状
直线、色块和编号
材质
纸张感或纯平数字表面
图像
编辑摄影、局部裁切和数据编号
动效
文字揭示与网格切换有明确节奏
近义词边界与组合规则

容易混淆

  • refined-minimalism瑞士编辑式允许字体和网格显性成为视觉内容，精炼极简更隐退。
  • neo-brutalism瑞士编辑式强调精确秩序，新野蛮主义强调裸露与冲撞。

适合 / 避免

适合：文化品牌、作品集、研究机构

避免：低龄儿童产品

可组合：kinetic-type、monochrome、creative-portfolio

MODEL PROMPT

采用瑞士编辑式：可见或隐含的严格网格；大字号字体成为主视觉；高对比信息层级。非对称网格、跨栏标题和精确基线。

避免随意错位、装饰压过内容结构。
03

基础视觉风格 · neo-brutalism

新野蛮主义

Neo-brutalism

核心词条

用粗边框、硬阴影、原色和直接排版暴露界面结构，以受控粗粝感形成强烈记忆。

它不是什么不是故意难用、随机丑化或取消所有对齐规则。

识别信号

  • 粗黑或高对比边框
  • 无模糊的硬投影
  • 直接而夸张的字号比例

排除信号

  • 柔光玻璃阴影
  • 无层级的随机碰撞

七类视觉语法

字体
粗体无衬线、等宽字与大号标签
色彩
黑白配原色或荧光撞色
布局
显式模块、硬切分区和受控错位
形状
直角卡片、胶囊标签、粗线图形
材质
印刷油墨、纸张或纯色数字面
图像
直接闪光摄影、涂鸦和贴纸
动效
短促位移、按钮压下和硬切换
近义词边界与组合规则

容易混淆

  • editorial-swiss新野蛮主义接受冲撞和粗糙，瑞士编辑式要求精确克制。
  • color-maximalism新野蛮主义由结构和边框定义，多彩极繁由完整色彩系统定义。

适合 / 避免

适合：创意工作室、音乐活动、年轻消费品牌

避免：严肃医疗操作流程

可组合：color-maximalism、grain-noise、creative-portfolio

MODEL PROMPT

采用新野蛮主义：粗黑或高对比边框；无模糊的硬投影；直接而夸张的字号比例。显式模块、硬切分区和受控错位。

避免柔光玻璃阴影、无层级的随机碰撞。
04

基础视觉风格 · glassmorphism

玻璃拟态

Glassmorphism

核心词条

在有意义的背景之上使用半透明、背景模糊和细描边建立分层，同时维持前景可读性。

它不是什么不是把所有容器调低透明度，也不是 Apple Liquid Glass 的同义词。

识别信号

  • 背景模糊可感知
  • 半透明容器带清晰边缘
  • 前后层级由透光关系建立

排除信号

  • 透明叠透明导致不可读
  • 无背景内容却强行模糊

七类视觉语法

字体
中等字重无衬线，关键数字保持实体色
色彩
冷蓝紫或暖粉橙渐变配高对比文字
布局
少量大玻璃面板承载主任务
形状
柔和圆角与薄描边
材质
磨砂、亚克力和微弱高光
图像
抽象光场、环境色和深景背景
动效
随滚动轻微视差与焦点切换
近义词边界与组合规则

容易混淆

  • skeuomorphism玻璃拟态模拟透光材质，拟物主义模拟具体物件和操作隐喻。
  • spatial-layers空间叠层是布局关系，玻璃拟态是表面材质。

适合 / 避免

适合：媒体控制、金融概览、沉浸式工具

避免：长文阅读、低性能设备重交互

可组合：gradient-mesh、dark-mode、spatial-layers

MODEL PROMPT

采用玻璃拟态：背景模糊可感知；半透明容器带清晰边缘；前后层级由透光关系建立。少量大玻璃面板承载主任务。

避免透明叠透明导致不可读、无背景内容却强行模糊。

基础视觉风格 · neumorphism

新拟态

Neumorphism

核心词条

以同色背景、成对明暗阴影和柔软圆角让控件像从表面压出或陷入，强调触感连续性。

它不是什么不是所有浅色圆角卡片，也不是简单的低对比界面。

识别信号

  • 控件与背景同色系
  • 明暗双阴影形成浮雕
  • 凸起与凹陷表达状态

排除信号

  • 只加普通投影
  • 交互状态无法辨认

七类视觉语法

字体
圆润中性无衬线，字号层级简短
色彩
低饱和浅色或深色单一色域
布局
围绕少量可触控组件组织
形状
大圆角、圆形旋钮和软胶囊
材质
柔软塑料、硅胶与压印
图像
少量图标和设备控制隐喻
动效
按压、回弹和阴影方向变化
近义词边界与组合规则

容易混淆

  • pastel-soft柔和粉彩只描述色彩，新拟态必须有成对阴影形成的表面结构。
  • refined-minimalism新拟态突出材质触感，精炼极简突出信息层级。

适合 / 避免

适合：设备控制、音乐播放器、概念型工具

避免：高密度数据后台、无障碍要求严格的公共服务

可组合：pastel-soft、microinteractions、mobile-native

MODEL PROMPT

采用新拟态：控件与背景同色系；明暗双阴影形成浮雕；凸起与凹陷表达状态。围绕少量可触控组件组织。

避免只加普通投影、交互状态无法辨认。

基础视觉风格 · skeuomorphism

拟物主义

Skeuomorphism

核心词条

用真实物件的形态、材质和操作反馈帮助用户理解数字功能，隐喻必须服务任务。

它不是什么不是堆砌木纹、金属和皮革，也不是复刻现实物件的全部细节。

识别信号

  • 现实物件与数字功能一一对应
  • 材质变化表达可操作性
  • 光影与空间方向保持一致

排除信号

  • 无功能意义的纹理
  • 不同光源和透视互相冲突

七类视觉语法

字体
与物件语境一致的标题字配清晰正文
色彩
来自真实材质但控制饱和度
布局
围绕单一物件隐喻建立操作区
形状
旋钮、拨杆、票据、卡槽和仪表
材质
金属、纸张、织物、玻璃或塑料
图像
高质量物件摄影或写实渲染
动效
模拟拨动、翻页、旋转和物理惯性
近义词边界与组合规则

容易混淆

  • neumorphism拟物主义指向具体物件，新拟态只模拟柔软表面起伏。
  • glassmorphism拟物强调实体对象，玻璃拟态强调透光界面层。

适合 / 避免

适合：音乐工具、烹饪与生活方式、叙事型零售

避免：多步骤企业表单

可组合：microinteractions、grain-noise、ecommerce

MODEL PROMPT

采用拟物主义：现实物件与数字功能一一对应；材质变化表达可操作性；光影与空间方向保持一致。围绕单一物件隐喻建立操作区。

避免无功能意义的纹理、不同光源和透视互相冲突。

基础视觉风格 · cyber-tech

赛博科技

Cyber Tech UI

核心词条

用深色空间、荧光信号、精密线框和高密度状态语言表达实时系统、监控与未来技术。

它不是什么不是所有深色页面，也不是随机加入霓虹和故障噪点。

识别信号

  • 深色背景上的状态荧光色
  • 线框、刻度或雷达式信息
  • 高密度但有主次的监控模块

排除信号

  • 无数据逻辑的装饰线
  • 整页同亮度霓虹

七类视觉语法

字体
窄体无衬线与等宽数据字
色彩
黑蓝底配青绿、橙或品红状态色
布局
中心任务区配外围监控模块
形状
细线网格、角标、节点和扫描框
材质
发光玻璃、金属与屏幕磷光
图像
地图、波形、设备轮廓和数据轨迹
动效
扫描、脉冲、路径生长与状态刷新
近义词边界与组合规则

容易混淆

  • dark-mode暗黑模式只改变明暗表面，赛博科技必须有实时状态和未来技术语法。
  • retro-os赛博科技面向未来，复古 OS 使用历史桌面组件。

适合 / 避免

适合：安全运维、游戏 HUD、实时监控

避免：长文内容站、医疗患者端

可组合：dark-mode、high-contrast、data-dashboard

MODEL PROMPT

采用赛博科技：深色背景上的状态荧光色；线框、刻度或雷达式信息；高密度但有主次的监控模块。中心任务区配外围监控模块。

避免无数据逻辑的装饰线、整页同亮度霓虹。

基础视觉风格 · retro-os

复古 OS

Retro Operating System

核心词条

用早期个人电脑的窗口、标题栏、像素图标和硬边框重组现代内容，制造清晰可读的系统怀旧感。

它不是什么不是直接复制 Windows 或 Macintosh，也不是普通像素艺术。

识别信号

  • 多窗口桌面构图
  • 一到三像素硬边框
  • 像素图标与系统状态条

排除信号

  • 受保护系统的逐像素复刻
  • 赛博霓虹取代历史组件

七类视觉语法

字体
像素字或等宽字配清晰正文
色彩
系统灰、蓝绿、黑白和单一强调色
布局
桌面、窗口、弹窗和菜单的层级
形状
直角窗体、像素按钮和旧式图标
材质
旧显示器、扫描线和轻微 CRT
图像
文件夹、光标、软盘和窗口内容
动效
窗口弹出、进度条和像素光标移动
近义词边界与组合规则

容易混淆

  • y2k-digital复古 OS 聚焦桌面操作系统语法，Y2K 聚焦千禧年的金属、泡泡和网络流行文化。
  • cyber-tech复古 OS 面向过去，赛博科技面向未来实时系统。

适合 / 避免

适合：创作者工具、电子音乐、游戏活动

避免：严肃医疗、极简长文

可组合：grain-noise、card-stack、creative-portfolio

MODEL PROMPT

采用复古 OS：多窗口桌面构图；一到三像素硬边框；像素图标与系统状态条。桌面、窗口、弹窗和菜单的层级。

避免受保护系统的逐像素复刻、赛博霓虹取代历史组件。

基础视觉风格 · y2k-digital

Y2K 数字怀旧

Y2K Digital Nostalgia

核心词条

以千禧年前后的网络乐观主义为核心，混合金属铬面、泡泡形态、低清数码影像和流行色。

排除信号

  • Windows 95 窗口成为主体
  • 只有通用霓虹渐变

七类视觉语法

字体
圆润未来字、扩展字和小号技术标签
色彩
电光蓝、泡泡粉、酸性绿、银灰
布局
贴纸式层叠、中心物件和漂浮导航
形状
泡泡、星形、椭圆和铬面字
材质
镜面金属、果冻塑料和数码噪点
图像
闪光摄影、旧数码相机和科技小物
动效
漂浮、旋转、镜面扫光和弹性形变
近义词边界与组合规则

容易混淆

  • retro-osY2K 是流行文化与材质语言，复古 OS 是窗口和系统组件语言。
  • cyber-techY2K 更乐观玩味，赛博科技更实时、监控和任务导向。

适合 / 避免

适合：潮流品牌、音乐与时尚、青年社区

避免：传统企业后台

可组合：gradient-mesh、kinetic-type、brand-marketing

MODEL PROMPT

采用Y2K 数字怀旧：铬面或果冻式三维字形；高饱和蓝粉绿与银色；早期互联网或数码设备符号。贴纸式层叠、中心物件和漂浮导航。

避免Windows 95 窗口成为主体、只有通用霓虹渐变。

奢华编辑

布局

28 个路由图鉴词

用于控制明暗与表面、组织信息与交互，或限定产品任务。它们不能越权冒充基础视觉风格。

Q01 · 修饰条件

暗黑模式

Dark Mode · dark-mode

将表面亮度、状态色和层级改写为低亮环境下仍清楚可读的界面修饰条件。

不是不是赛博科技风格，也不是把白色简单反相为黑色。

  • 深色分层表面
  • 高可读前景文字
  • 状态色亮度受控

Q02 · 修饰条件

高对比

High Contrast · high-contrast

通过显著明度差、清晰边界和强焦点状态提升识别速度与可访问性。

不是不是每个元素都用纯黑纯白，也不是视觉上的持续刺眼。

  • 文本背景明度差明显
  • 焦点和边界可辨
  • 状态不只依赖颜色

Q03 · 修饰条件

黑白单色

Monochrome · monochrome

用单一色相及其明度阶梯组织层级，让排版、形状和内容承担主要表达。

不是不是把彩色图简单去饱和，也不是自动等于极简。

  • 单一色相占主导
  • 明度层级明确
  • 强调依靠尺寸形状或纹理

Q04 · 修饰条件

柔和粉彩

Soft Pastel · pastel-soft

以高明度、低到中饱和色彩降低压迫感，保持足够文字对比和状态区分。

不是不是新拟态，也不是把所有元素变成浅粉色。

  • 高明度低饱和色板
  • 柔和但可区分的状态色
  • 正文仍保持可读深度

Q05 · 修饰条件

不是不是压缩失真，也不是覆盖一层强噪声就算风格。

  • 全局纹理强度克制
  • 纹理与品牌材料一致
  • 正文区域保持清晰
